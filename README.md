# Kotori Assets

Public CDN-style asset repo for the Kotori website project.

## Files

- `kotori-fake-b-roll-1.mp4` — hero/background video B-roll

## Usage

Files are accessible via GitHub raw URLs:

```
https://raw.githubusercontent.com/Mystigin/kotori-assets/main/kotori-fake-b-roll-1.mp4
```

Or via jsDelivr CDN (faster, cached, recommended for production):

```
https://cdn.jsdelivr.net/gh/Mystigin/kotori-assets@main/kotori-fake-b-roll-1.mp4
```
